Requisito: Ticket APIA de ChileCompra

Para usar este addon debes contar con un Ticket de acceso a la API de Mercado Público, emitido por la Dirección de Compras y Contratación Pública (DCCP — ChileCompra). Es gratuito y de uso público.

✅ Gratuito
El ticket es gratuito para cualquier usuario. Sin costo asociado al registro.
📧 Por solicitud
Se solicita en api.mercadopublico.cl opción "Solicitud de Ticket". Se envía por correo.
⚡ 10.000 req/día
Cada ticket tiene una cuota de 10.000 peticiones diarias (suficiente para uso normal).
🔒 Por IP
ChileCompra monitorea el uso por IP. El uso excesivo puede generar bloqueos temporales.

Preguntas frecuentes

Todo lo que necesitas saber sobre Licitaciones Públicas

¿Qué es el ticket APIA y por qué lo necesito? +
El ticket APIA es una credencial gratuita emitida por ChileCompra que permite acceder a la API oficial de Mercado Público. Sin él, ValidaNet no puede conectarse a los datos en tiempo real de licitaciones y órdenes de compra. Lo solicitas en api.mercadopublico.cl y te llega por correo.
¿Tiene costo el ticket APIA? +
No. El acceso a la API de Mercado Público es completamente gratuito para todo tipo de usuario. Solo requiere registrarse en api.mercadopublico.cl.
¿Cuántas consultas puedo hacer por día? +
Cada ticket tiene una cuota de 10.000 peticiones diarias, definida por ChileCompra. Es suficiente para uso normal en una OTEC.
¿ValidaNet postula automáticamente en mi nombre? +
No. ValidaNet muestra y analiza las licitaciones disponibles. La postulación formal se realiza directamente en mercadopublico.cl por el usuario.
¿Para qué tipo de instituciones es útil? +
Principalmente para OTECs, empresas de capacitación, consultoras educativas y proveedores de servicios que quieran venderle al Estado chileno.
